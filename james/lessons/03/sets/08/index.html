Drill 1 — Repeated Growth (Compounding)

6 Problems · 12 min
⏱️ Set a timer for 12 minutes. Work fast but write the multiplier every time before you calculate.

Show ALL work. Write the growth/decay multiplier FIRST, then apply it the correct number of times. Round money answers to the nearest cent.

Formulas Growth: new = old × (1 + r)^n Decay: new = old × (1 − r)^n r = rate as a decimal n = number of periods

Drill 2 — Percent Vocabulary: Value or Difference?

6 Problems · 10 min
⏱️ Set a timer for 10 minutes. Decide Value vs. Difference BEFORE you touch a calculator.

For each stem, DO NOT calculate yet. First decide: is the question asking for a single value, or a difference/gap between two values? Circle "Value" or "Difference," then solve.

Key Vocabulary "increased FROM" → original value "increased TO" → new value "how much more/less" → difference percentage point ≠ percent
