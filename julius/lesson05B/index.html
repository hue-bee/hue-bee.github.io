CAT decision protocol

Protect the answer before it locks

The real skill is not “never hesitate.” It is deciding what evidence is sufficient before advancing.

1Parse

What is asked? What unit should the answer have?

2Model

Equation, multiplier, ratio, weighted sum, or diagram?

3Check

Sign, scale, unit, and whether every condition was used.

4Commit

Select once; do not carry doubt into the next item.

Math + standalone ELA

Answer before advancing. Once advanced, the response is closed.

ELA passage set

Review within the set exactly once; after submission, the set is closed.

Cluster 3 · Algebra language

Translate relationships, not keywords

Build a mathematical skeleton that preserves operation order and grouping.

“subtracted from”

Reverse the order: A subtracted from B means B − A.

“per”

Divide the first quantity by the reference quantity.

“of”

Usually multiplication—but identify the base first.

“reciprocal”

Swap numerator and denominator.

Think before calculating
Which English phrases change the order of the numbers? Which phrases tell you to preserve parentheses?
Bracket-first habit

Write one pair of brackets for every named quantity: “the sum of …,” “the product of …,” or “the reciprocal of ….” Then connect those quantities.

Cluster 4 · Geometry

Linear scale and area scale are different species

If one dimension changes by factor a and another by factor b, area changes by factor ab.

length L
width W
dimensions scale
length 2L
width 4W
new area = (2L)(4W) = (2 × 4)(LW)
Think before calculating
Why is adding the scale factors unreliable? Which parts of the area formula receive a factor?
Power-of-dimension rule

Length is one-dimensional; area uses two dimensions. Uniform scale factor k produces area factor k², but unequal scaling uses the product of the separate factors.
