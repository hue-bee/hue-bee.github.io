Part E: Counting Principle

3 Problems

Counting outcomes is multiplication in disguise. Multiply the number of choices at each independent step; only add when choices are "either/or" alternatives.

RememberTotal = choice 1 × choice 2 × ..."AND" → multiply"OR" → add
Problem 12 L1

A cafe offers 5 bagel choices and 4 spread choices. How many different bagel-and-spread combinations are possible?

Answer
Problem 13 L3

A padlock code uses 3 digits from 0–9, and no digit may repeat. How many codes are possible?

Answer
Problem 14 L4

A spinner has 4 equal sections and is spun 3 times, with each result recorded in order. How many possible sequences are there, and how would you write that total using an exponent?

Answer
SHSAT Trap — add vs. multiply: Independent steps that happen together get multiplied. Only alternatives that replace each other (either/or) get added.
