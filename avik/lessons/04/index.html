0:05–0:13 · Error Audit

Diagnose the First Broken Step

Translation
The equation does not match the story. Ask: “What sentence did my equation claim?”
Arithmetic
The setup is faithful, but computation breaks. Keep one operation per line and estimate first.
Wrong Target
You solved for a useful quantity, but not the requested one. Box the question before starting.

Point to the earliest line that became unreliable. If that line were repaired, would every later line now make sense?

0:17–0:21 · Pattern Recognition

Six Skeletons, Hundreds of Costumes

Total / Difference
part + part = total; larger − smaller = gap
Rate × Time
amount = rate × time; label every unit
Part–Whole
parts add to whole; fractions refer to the same whole
Percent-Of
part = percent × base; identify the base
Consecutive Integers
x, x+1, x+2; even/odd advance by 2
Combined Quantity
separate contributions first, then add or equate
Clever shortcut: Ignore the story’s decorations. Ask which quantity is being assembled, compared, repeated, or scaled.

0:24–0:27 · Total / Difference

Build the Whole Before Computing

Think first
If Lena has 7 more points than Omar, which bar must be longer? Does “7 more than Omar” mean add 7 to Lena or add 7 to Omar?
Omar = x   |   Lena = x + 7   |   total = x + (x + 7)
SHSAT Trap: Reversing “Less Than”
“3 less than twice a number” starts with twice the number, then removes 3. Preserve the order of the relationship.

0:27–0:30 · Rate × Time

Let Units Do the Policing

The unit equation
miles = (miles/hour) × hours
The “hours” cancel, leaving the requested distance unit.
Split-rate rule: never average rates unless the time or distance weights justify it. Compute each segment’s contribution separately.

Practice · Percent

Direct Base vs. Hidden Base

5Level 2

6Level 4

SHSAT Trap: Discount Is Not the Remaining Percent
A 15% discount leaves 85% of the original price. The sale price equals 0.85 × original, not 0.15 × original.

0:47–0:49 · Elimination

Name the Trap, Then Remove It

Unsupported
Possible, but the passage never supplies enough proof.
Distorted
Uses a real detail but changes its meaning.
Too Broad
Claims more people, time, or causes than the text allows.
Too Narrow
Mentions one detail but misses the passage-level conclusion.
Wrong Paragraph
True elsewhere, but not relevant to this question.
Outside Knowledge
May be true in life; cannot be proved from this text.
Two-finalist test: Which choice requires fewer assumptions and is supported by more direct evidence?
