## 4. Ability — Detailed Scope (Priority #2)

Matrices (3/20) and Paper Folding (2/10) are at chance level. This section rewards fixed procedures, so it is the fastest to improve. Many wrong answers sit one letter from the key (N→M, C→D): on the computer test bubbling isn't the issue, so he is most likely stopping at the *partially* correct distractor. Fix: verify **every** rule before choosing.

### Paper Folding (Session 1) — use real paper and a hole punch first
1. Track each fold: which half moves, where the fold line lands.
2. Count layers under the punch — each layer = one hole.
3. Unfold in reverse order, mirroring holes across each fold line in turn.
4. Eliminate any choice with the wrong hole count or holes not symmetric across the fold lines.

### Figure Matrices (Session 2)
- Rule checklist: **shape · number of sides/parts · shading · size · rotation · reflection · inside/outside · count**.
- Find the rule across the row **and** down the column; name what is added, removed, or moved.
- State the rule in one sentence and *picture the answer before looking at the choices* — the main defense against near-miss distractors.

### Figure Classification (Session 3)
- Find the one feature all given figures share; test every choice against it.
- If more than one choice fits, the rule is too loose — add a second feature (shading, side count) until one choice remains.
- Pacing target: roughly 35–40 seconds per Ability item (third-party estimate). Build toward it with weekly timed sets.
