Every Diagram Hides an Equation

Four facts to retrieve
  • Triangle interior angles total 180°.
  • Quadrilateral interior angles total 360°.
  • Isosceles triangles have equal base angles.
  • Vertical angles are equal; a straight line totals 180°.
fact → equation → solve → check

Use the Most Specific Fact

1

Name the structure

The matching side marks make the triangle isosceles, so the two base angles match.

2

3

Solve and test

144 + x = 180, so x = 36. Check: all three angles total 180°.

Figure Classification:
One Rule, Then a Tighter Rule

A useful rule must fit all three given figures and reject the tempting near-matches. If two choices survive, the rule is still too broad.

Classification Protocol

Describe, Test, Tighten

1
Describe the shared feature
Use precise words: count, position, shading, size, direction, inside/outside.
2
Test every choice
Do not stop at the first figure that “looks similar.”
3
Tighten if needed
Add a second feature until exactly one choice remains.
Strong rule sentence: “Each figure has exactly two nested shapes, the inner shape matches the outer shape, and only the inner shape is shaded.”
TACHS Trap: A Rule That Fits Only Two Stems
Check the proposed rule against stem 1, stem 2, and stem 3 separately. One counterexample breaks the rule.
