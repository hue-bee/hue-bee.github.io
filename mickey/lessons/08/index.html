Make the target a unit

Questions that expose the slip

  • What is the reference quantity in each “of” statement?
  • What equation defines \(p\), rather than just \(\frac{C}{B}\)?
  • If a ratio were \(1\), what percent would describe it?

Efficient method

Write two expressions for the same sample, then eliminate that sample. Keep the requested percent symbolic until the final conversion.

Use a quantity ledger: weight → ratio → percentage. The last line must have the representation requested by the prompt.

\(\frac{A}{B}=\frac{468}{100}\)
\(\frac{A}{C}=\frac{0.780}{100}\)
\(\frac{C}{B}=\frac{p}{100}\)

Count faces before expanding

Questions

Which dimension is missing? How can the base area supply it?

How many congruent face pairs exist? Which units would expose an accidental volume computation?

Efficient decomposition

Use \(S=2B+Ph\), where \(B\) is base area and \(P\) is base perimeter. First obtain width from \(B=lw\); then construct \(P\) from both base dimensions.

Check this against \(2lw+2lh+2wh\). The two methods should count exactly the same six faces.

A correspondence is a function

A triangle name is an ordered list, not a bag of letters. First pair equal angles; then map each endpoint of a side.

Reduce six pairs to three types

Structural compression

Four angles yield six unordered pairs, but vertical-angle symmetry collapses them into three types.

Let one angle be \(\theta\). What is its opposite? What is an adjacent angle? List pair types before substituting the expression in \(x\).

A faster invariant check

Every angle measure here is positive, and adjacent angles are supplementary. Test whether a candidate expression can satisfy those constraints before doing long expansion.

Could a numerical test of one allowed angle disprove “could be”? Why does a universal sign argument do more?

Truth is only the first filter

Build the comparison contract

A comparison needs two subjects, one common axis, and a supported relationship.

Which axis matters here: dates, existence of modules, or scope of modularity? Which notes establish what each hypothesis includes?

Compress before choosing

Make a two-row matrix: hypothesis | low-level systems | high-level systems. Fill it from the notes, not from memory.

Test each candidate twice: “Is every clause supported?” and “Does it explicitly perform the requested comparison?”
